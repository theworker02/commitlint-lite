# commitlint-lite

<img src="docs/logo.svg" alt="commitlint-lite mark" width="72" height="72">

![version 1.00](https://img.shields.io/badge/version-1.00-C9A227?labelColor=0B1F33)
![npm 1.0.0](https://img.shields.io/badge/npm-1.0.0-0B1F33)

Read a commit message file or argv and require a conventional subject: feat|fix|docs|chore|refactor|test|ci, optional scope, then a description.

## Install

```bash
git clone https://github.com/theworker02/commitlint-lite.git
cd commitlint-lite
npm install -g .
```

Package version: **1.00** (`1.0.0`).

## Usage

```bash
commitlint-lite feat:
```
