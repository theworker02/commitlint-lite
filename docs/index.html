commitlint-lite

Require commit subjects matching feat|fix|docs|chore|refactor|test|ci with an optional scope.

Overview

Full commitlint stacks are heavy for tiny repos. commitlint-lite is one regex and a clear exit code you can drop into a git hook.

Solo maintainers and small teams who already use conventional commits and want a portable checker.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/commitlint-lite.git
commitlint-lite --help
node src/cli.js --help

Usage

Synopsis: commitlint-lite [options] <file-or-message>

See the full CLI reference for every flag, exit code, and example.

commitlint-lite 1.00 (1.0.0)

Usage:
  commitlint-lite [options] <file-or-message>

Require a conventional subject:
  ^(feat|fix|docs|chore|refactor|test|ci)(\(.+\))?: .+

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

If a single argument is a path that exists, the file is read
(first non-empty, non-# line). Otherwise all arguments are the message.

Examples:
  commitlint-lite "feat: add scan"
  commitlint-lite .git/COMMIT_EDITMSG

Examples

Success

commitlint-lite "fix(cli): handle empty stdin"
{"ok":true,"subject":"fix(cli): handle empty stdin"}

Failure

commitlint-lite "WIP"
{"ok":false,"subject":"WIP"}

Exit code is 1.
